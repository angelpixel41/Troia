# Refinamento visual — 21/10/2026

Referência analisada: https://www.troiadistribuicao.com.br/#produtos

O original apresenta categorias, marcas e várias chamadas semelhantes para atendimento. A nova versão prioriza o portfólio, usa composições das embalagens transparentes e organiza o conteúdo em uma hierarquia editorial com preto, vinho e fundos claros.

## Implementação

- Abertura com Pilão, Marilan e Veja, sem editar os arquivos de produto aprovados.
- Vitrine antecipada na página, filtros acessíveis e contagem de resultados.
- Respostas expansíveis a dúvidas comerciais baseadas nas informações existentes.
- Ajustes para desktop, tablet e celular; navegação por teclado e movimento reduzido.
- Informações institucionais, telefone, e-mail e destino do mapa preservados. Referências geográficas antigas do original não foram importadas.
- Formulário demonstrativo preservado conforme os commits anteriores. Nenhum envio ou armazenamento foi adicionado.

## Publicação real

O domínio `troia.pixelinfinite.com.br` é servido pelo **Cloudflare Worker `troia`**, com arquivos estáticos. O README anterior descrevia Pages. O push para o GitHub, sozinho, não publica a alteração nesse Worker.

No PowerShell, a partir da raiz do repositório:

```powershell
./tools/deploy.ps1
```

O script prepara apenas os arquivos públicos em `.deploy/` e usa Wrangler 4.151.3 com a autenticação existente. Fontes, Git e documentação não são enviados. `.deploy/` e `.wrangler/` são ignorados pelo Git.

O domínio original `www.troiadistribuicao.com.br` foi usado como referência e não é o destino dessa publicação.
